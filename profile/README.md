### What We Build

Phronesis trains Computer Science students, fresh graduates, and transitioning software engineers through intensive **6-week (90-hour) engineering tracks** built around small hands-on **Lab Pods (15–20 engineers led directly by the instructor)**, weekly code reviews, and a live Final Project defense.

We do not issue participation certificates. Every credential verified on [`phronesis-tech.com/verify`](https://phronesis-tech.com/) represents shipped code, documented engineering decisions, and a live technical defense.
